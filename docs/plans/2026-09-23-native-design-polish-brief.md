# Brief: unify and polish the Turf Review native design

James asked for this on 23 September 2026. You have full authority to plan, build, verify and ship without asking him for approval. Stop only for a genuine blocker you cannot resolve, such as a credential only he holds.

## Goal

The iPhone, iPad and Mac apps work, but they do not look designed. They use several unrelated color systems, spacing and type are inconsistent, and nothing moves. Make them feel like one coherent, calm, native reading app, with subtle, purposeful motion. Apply restraint: quiet, precise, well-crafted detail, not decoration.

## Workflow

Define and run a medium workflow of fewer than 10 agents, using the Workflow tool (load `workflow-authoring` first). James has explicitly opted in. A suggested shape; improve it if you have a better one:

5. **Verify and ship.**

## Codebase facts

- **Code:** `~/GitHub/turfterrace-review/TurfReviewNative` is SwiftUI, iOS 17 and macOS 14, generated by `xcodegen` from `project.yml`. Run `xcodegen generate` after adding files; it reproduces the checked-in project exactly.
- **Theme:** `TurfReviewNative/Support/TurfTheme.swift` today has an accent of `#39775B`, uses system red, green and orange for status, and has a `plum` that maps to secondary.
- **Reader:** `HTMLDocumentView.swift` wraps content in inline CSS (`wrap(_:)`) and injects scripts. Its colors conflict with the Swift theme:
  - `--terracotta` is actually green;
  - leftover terracotta `rgba(192,96,48)` in link underlines and blockquotes;
  - teal `#007c89` and `rgba(0,124,137)` for selection and choice targets;
  - gold `rgba(201,154,56)` for open targets;
  - olive `#687f4e` for approve;
  - brick `#c95f45` for reject;
  - coral `rgba(224,96,64)` for saved annotations.

  Unify these with the Swift tokens, in light and dark.
- **State:** `ReviewStore` is `@Observable`; views take `let store: ReviewStore`. Keep it that way; views should read only what they render.
- **Performance work to preserve (23 September):** date-sort fast path, shared detail requests, the 30 s foreground-refresh throttle, the indexed highlight script (the `TextIndex` in the reader JS) and the WebKit warm-up. Do not undo them. Keep animations cheap: no per-frame work on the main thread, and no animating the web view's content.
- **Behaviour must not change:** decisions, annotations, review targets, offline downloads, reading position, deep links and push notification taps. Keep all copy that states facts.
- **Uncommitted work in the tree:** the working tree holds uncommitted work from two earlier agents. Don't discard or revert anything you didn't write. Commit only if you can separate your own changes cleanly; otherwise leave them uncommitted and say so in your report.
